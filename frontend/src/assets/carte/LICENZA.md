# Carte napoletane

Le 41 immagini SVG di questa cartella (40 carte + dorso) vengono da
[SONDLecT/woodcut-napoletane](https://github.com/SONDLecT/woodcut-napoletane),
mazzo napoletano in vettoriale tracciato da un mazzo stampato a Napoli nel 1902.

Licenza **CC0 1.0** (dominio pubblico): uso libero, anche commerciale, senza
obbligo di attribuzione. L'attribuzione qui sopra e' una cortesia, non un obbligo.

- `*‑asso.svg`, `*‑02.svg` … `*‑07.svg`, `*‑fante.svg`, `*‑cavallo.svg`, `*‑re.svg`:
  le carte a colori pieni (`colori/` del repository originale).
- `dorso.svg`: il dorso, con il motivo a rombi del tipografo.

Le stesse carte esistono anche in versione solo contorno (`cards/` del
repository originale), utile se serve un mazzo monocromatico.
